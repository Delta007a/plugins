# Ночная перезагрузка для Xiaomi TV Box S 2nd Gen

Android TV 14 / MiTV-AFKR0. Приложение пытается ежедневно в 04:00 открыть системные настройки → «Система» → «Перезагрузить» через службу специальных возможностей. Root и компьютер не нужны.

**Настройка:** установи debug APK, открой «Ночная перезагрузка», нажми «Разрешить управление меню» и включи соответствующую службу в специальных возможностях. Вернись и нажми «Включить расписание». Час меняется кнопками +/−. Проверочные мастера не нужны. Автозапуск «Смотрёшки» после перезагрузки должен быть настроен отдельно.

**Ограничение:** Android может не разрешить открыть настройки из фона, а прошивка может изменить системное меню. На реальном устройстве приложение пока не испытано; если ОС полностью зависла, такое приложение не сможет её перезагрузить.

**Сборка:** GitHub Actions → «TV Night Restart — build APK» → артефакт «TVNightRestart-APK» после успешной сборки.
